# UI Spec — Logs Tab Tile "1b: Header Band"

Same context, behavior, palette, typography, page header, tile-container layout, data queries, empty state, and accessibility rules as spec-1a-card-overview.md — **only the tile anatomy differs**. Read that file first; this file defines only the deltas.

## Tile anatomy

Card: white bg, `1px solid #e1dfdd`, radius 6px, `overflow:hidden`, `cursor:pointer`, column flex, entire card clickable → associated view.
Hover: `box-shadow:0 3px 10px rgba(0,0,0,0.14)` (border stays grey — the band carries the brand).

### 1. Header band
- Bg `#323130` (charcoal), white text, padding `12px 16px`, `border-bottom:3px solid #c8102e` (brand rule)
- Flex, center-aligned: entity name UPPERCASE, 13px/600, letter-spacing 0.3px ("RISKS", "PROJECT DEPENDENCIES", "CHANGE REQUEST LOG")
- Right-aligned: total record count, 22px/600, line-height 1

### 2. Body (padding `14px 16px`, column flex, gap 12px, `flex:1`)

**2.1 Status chip row** (flex, gap 6px, wrap) — one chip per status with count, ordered urgent→done. Chip: 11px/600, padding `3px 9px`, radius 10px.
- Urgent/red: bg `#fbeaed`, color `#c8102e`, border `1px solid #f2c6cd` — e.g. "3 high severity", "1 blocked", "2 rejected"
- Warning/rose (only when a mid-urgency tier exists): bg `#fdf3f5`, color `#a50d26` — e.g. "2 at risk"
- Neutral greys: bg `#f3f2f1`, color graded by urgency `#323130` → `#605e5c` → `#8a8886`
- Hide zero-count chips. The severity/blocked call-out is the first chip, not a separate element.

**2.2 Stat grid** — `display:grid; grid-template-columns:92px 1fr; gap:6px 10px`, 12px text. Labels in `#8a8886`, values in `#323130`. Four rows:
- `Latest` → record name as red link (opens record form)
- `Last activity` → relative time, spelled out ("2 days ago")
- `Owners` → avatar stack: 22px circles, initials 9.5px/700 white, `2px solid #fff`, overlap `margin-left:-6px`, bg cycle `#c8102e` / `#605e5c` / `#8a8886`, max 3
- `Trend` → 8 weekly bars, 6px wide, 2px gap, max height 20px, square corners; oldest 4 `#d9d7d5`, next 3 `#b8b6b4`, current week `#c8102e`

### 3. Footer
- `margin-top:auto` (pins to bottom for equal-height cards), top hairline `1px solid #edebe9`, padding-top 10px
- Single red link, 12px/600: "Open {Entity} view →" (e.g. "Open Risks view →") — same target as card click

## Per-tile content mapping

Identical to spec-1a (same statuses, alert conditions, latest/owners/trend sources); the only difference is presentation: alert lives as the lead chip in the chip row, and the count lives in the header band instead of a big in-body number.
